IX-Ray SDK — ИИ-помощник, версия 0.2.0

ОСНОВА
Официальный SDK ixray-team/ixray-1.6-stcop, ветка develop,
bcf4dd51d6433fdee29ece01f7ce40af16666dec (10.11.2026).
Коммит интеграции и дата сборки записаны в build-info.json.
Это отдельная тестовая установка SDK. Не копируйте её EXE в старый SDK.

ПЕРВЫЙ ЗАПУСК
1. Запустите установщик Windows x64 и выберите отдельную папку.
   Альтернатива — распаковать Portable ZIP в доступную для записи папку.
2. Запустите ярлык либо Launch-LevelEditor.cmd.
3. Откройте через меню редактора панель «ИИ-помощник».
4. Нажмите «Проверить подключение», затем «Войти через ChatGPT».
   Официальный вход происходит в системном браузере; пароль в SDK не вводится.
5. При проблеме с браузерным входом используйте вход по коду устройства.
   Его доступность зависит от настроек безопасности вашего аккаунта.
6. Откройте rawdata\levels\ai_test.level. Команда для проверки:
   «Найди ai_cube, выдели его и скажи его координаты».
7. Затем: «Сдвинь его на 1 метр по мировой оси X и проверь координаты».
   После этого проверьте отмену и повтор штатными Undo/Redo.

СВОИ РЕСУРСЫ
Установщик позволяет выбрать существующую папку rawdata проекта.
Для первой проверки оставьте тестовые ресурсы. Внешние библиотеки моделей,
текстур и игровых материалов должны быть совместимы с этой ревизией SDK.
Установщик не переносит ваши проекты из другого SDK автоматически.

ВОЗМОЖНОСТИ
Чтение сцены и выделения; поиск по имени, классу, модели, текстуре;
выделение и наведение камеры; перемещение, поворот и масштаб;
дублирование статических экземпляров; размещение библиотечной модели;
Undo/Redo; чтение и точечная правка материалов экземпляра;
проверка отсутствующих текстур; снимок viewport; сохранение новой копии.
Выбирайте модель в панели из списка, возвращённого официальным клиентом.
Список моделей не гарантирует доступ к каждой: его подтверждает реальный
успешный запрос с учётом вашего плана, региона, настроек и текущих лимитов.
Отдельный оплачиваемый API-ключ программа не требует и не подставляет.

КОМАНДЫ И ОТМЕНА
Координаты — метры, система левая, +Y вверх; углы — градусы Эйлера XYZ.
Сдвиг задаётся по мировым осям. Масштаб — множитель вокруг pivot объекта.
За один вызов обрабатывается не более 128 объектов или поверхностей.
Большой пакет более 100 элементов требует одного подтверждения в панели.
Пакет изменений геометрии/материалов создаёт один проверенный шаг Undo.
При отключённом Undo изменения блокируются.
Выделение, камера и сохранение копии не создают шаг Undo геометрии.
Кнопка «Остановить» блокирует новые команды и запрашивает остановку модели.
Уже выполненное действие отменяется отдельным штатным Undo.
При таймауте исход может оставаться неизвестным: используется проверка
идентификатора операции, автоматического повторного сдвига/создания нет.
После загрузки другой сцены и Undo/Redo старые ссылки объектов недействительны.

МАТЕРИАЛЫ И СОХРАНЕНИЕ
Изменяется только указанная поверхность экземпляра сцены.
Совпадение текстур не объединяет поверхности. Библиотечный .object не
перезаписывается AI-командами, в том числе при оптимизации загрузчиком.
Копию сохраняйте по новому абсолютному пути .level: существующий файл или
его каталог частей не перезаписываются. Ограничение пути — 240 байт UTF-8.
Для повторного открытия копии используйте обычное меню редактора.

ДАННЫЕ И ПОДКЛЮЧЕНИЯ
История и сессия Codex хранятся отдельно для этой установки SDK в
%LOCALAPPDATA%\IXRay\AI\<идентификатор проекта>.
Существующий профиль %USERPROFILE%\.codex не заменяется.
Переписки, проекты и память сайта ChatGPT не импортируются.
Каждая запущенная копия LE создаёт собственный процесс и локальный канал;
панель управляет именно своим редактором. Сетевой порт в интернет не открывается.
Пароли, cookies и токены не извлекаются из браузера.

ДИАГНОСТИКА
Кнопка «Собрать диагностику» создаёт ZIP и показывает фактический путь.
Включаются версии, состояния соединений, коды ошибок и метаданные операций.
Авторизация, токены, переписка, сцены и ресурсы в ZIP не включаются.
При ошибке входа смотрите сообщение официального клиента: подписка или
ограничение аккаунта не переключаются на оплату API автоматически.

ОБНОВЛЕНИЕ И ОТКАТ
Закройте SDK перед обновлением. Совместимое обновление этой отдельной
установки сохраняет предыдущие программные файлы в _previous_build.
Для отката закройте SDK и запустите Rollback.cmd. Новые файлы сохраняются
в отдельной папке; история в LOCALAPPDATA и пользовательские ресурсы остаются.
Перед следующим обновлением перенесите прежнюю резервную копию отдельно.
Удаление программы не должно использоваться для удаления своих ресурсов.

ТРЕБОВАНИЯ
Windows x64; для UTF-8 путей процесс использует поддержку Windows 10 1903+
либо Windows 11. Старые версии Windows 10 для кириллицы не проверены.
Интернет необходим для официального входа и запросов модели.
Node.js, Codex и библиотеки MCP уже входят в бинарную поставку;
компиляторы, Python, ручное редактирование JSON/TOML пользователю не нужны.
SHA-256 загружаемых при сборке архивов зафиксированы в runtime-lock.json.
Фактические проверки и ограничения смотрите в TEST_REPORT_RU.txt.
