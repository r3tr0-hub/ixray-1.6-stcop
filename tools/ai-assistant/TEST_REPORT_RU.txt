WINDOWS RELEASE
Актуальный результат компиляции и упаковки фиксируется Windows CI.
В бинарной поставке build-info.json и CI_EVIDENCE.json содержат коммит,
параметры сборки и фактически выполненные проверки.
Нативный тестовый режим -ai-selftest пишет ai-selftest-report.json
в _appdata_ixray_; результат нельзя считать пройденным без этого отчёта.

ЛИЧНЫЙ ВХОД И ЖИВАЯ МОДЕЛЬ — ОЖИДАЕТ ПРОВЕРКИ ПОЛЬЗОВАТЕЛЕМ
Полная цепочка «панель → ваша модель → MCP → открытая сцена → ответ»
требует личного официального входа. Вход и inference не подменены
имитацией. Доступ к конкретной модели и лимиты аккаунта не подтверждены.
Следуйте проверочным запросам из fixtures/README_RU.txt.

Проверки протокола с имитацией ответов и компиляция не заменяют запуск LE.
Состояния Windows CI и живого теста указываются отдельно при выдаче пакета.
