Тестовые ресурсы ИИ-помощника IX-Ray

Сцена: rawdata\levels\ai_test.level
Модель: ai_test\cube
Объект сцены: ai_cube
Размер: 1 × 1 × 1 м; центр основания (0, 0, 0), верх Y = 1.
Поверхности: left_half и right_half, обе используют ai_test\checker.
Другая существующая текстура: ai_test\alternate.

Ресурсы созданы специально для проверки. Пользовательская локация и файлы
оригинальной игры для геометрии и текстур теста не требуются. Библиотеки
шейдеров и игровых материалов берутся из согласованной поставки SDK.

Проверочные запросы:
1. Найди объект ai_cube и выдели его. Что сейчас выделено?
2. Сдвинь выделенный объект на 1 метр по мировой оси X. Проверь координаты.
3. Отмени последнее изменение. Проверь X = 0. Повтори изменение: X = 1.
4. Покажи материалы объекта. Измени только поверхность с индексом 0 на
   ai_test\alternate. Поверхность 1 должна остаться ai_test\checker.
5. Покажи результат в окне редактора.
6. Сохрани сцену в отдельную копию с новым именем.
7. Открой копию обычной командой редактора и снова прочитай материалы:
   поверхность 0 alternate; поверхность 1 checker.

Файл модели rawdata\objects\ai_test\cube.object не должен изменяться.
Его SHA-256, как и остальных ресурсов, записан в ai-fixture-manifest.json.

Генератор generate_fixture.py воспроизводит точные исходные байты:
python generate_fixture.py --output ПАПКА_ДЛЯ_РЕСУРСОВ
Это команда для разработчика сборки; пользователю Python не нужен.

Фактически выполнено в Linux: генерация; проверка DDS/TGA независимым
декодером Pillow; проверка структуры chunk-файлов и индексов геометрии.
Загрузка в настоящий Windows Level Editor должна быть отражена в общем
отчёте тестов отдельно; данная проверка её не заменяет.
